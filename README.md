# מרוץ הגלידה

משחק דפדפן לשני שחקנים: עוקבים אחר רצף המספרים של הגלידה, ומי שמשלים רצף נכון צובר נקודה. הראשון שמגיע ל־10 נקודות מנצח.

## הפעלה

1. פותחים את `home.html` בדפדפן עדכני.
2. לוחצים על **Start** כדי לעבור למשחק.
3. אין צורך להתקין תלויות או להפעיל שרת — המשחק משתמש ב־HTML, CSS ו־JavaScript רגילים.

## איך משחקים

- בכל תור מופיעה גלידה עם רצף של חמישה מספרים. לוחצים על המספרים לפי הסדר, בהתאם למקרא הצבעים הממוספר שמוצג ליד כל שחקן.
- שחקן 1 משתמש בשורת המספרים העליונה במקלדת.
- שחקן 2 משתמש במקשי המספרים שבצד הימני של המקלדת (NumPad).
- רצף נכון מעניק נקודה. רצף שגוי לא מעניק נקודה, והמשחק ממשיך לגלידה הבאה.
- הראשון שמגיע ל־10 נקודות מוכרז כמנצח.

## מבנה הפרויקט

- `home.html` — מסך ההסבר והמעבר למשחק.
- `index.html` — מסך המשחק.
- `scripts/` — קוד המשחק, השחקנים, הגלידות והקלט מהמקלדת.
- `styles/main.css` — עיצוב ותצוגה מותאמת למסכים שונים.
- `assets/` — תמונות המשחק.
